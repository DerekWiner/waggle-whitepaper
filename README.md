# Waggle Whitepaper Archive

This repository previously hosted a Waggle publication with additional framing around decentralised education, AI and well-being.

The canonical Waggle Manifesto is now identified in [Waggle-Manifesto](https://github.com/DerekWiner/Waggle-Manifesto). The PDF `Waggle_Manifesto_Clean.pdf` was found in both repositories with the same Git blob SHA during the audit.

## Preserved framing

The original framing described a convergence of decentralised education, AI and well-being. Preserve that framing as supplementary context in the canonical publication rather than treating this repository as a second canonical source.

## Status

This repository is retained as a transition and historical source. It is not archived or deleted. Its contents should not be interpreted as evidence that the proposed Waggle capabilities are implemented or deployed.
